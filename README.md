# Project title:
Equilibrium model for process-based optimization and material screening for methane and CO2 removal from diluted sources
# Description and motivation: 
This project provides codes, input data, and results for an equilibrium-based process optimization approach to screen materials from the NIST new sorbents database 
The process is a Vacuum Temperature Swing Adsorption (VTSA) cycle which is modeled by equilibrium assumption targeting methane (and CO2) removal. The process considers ternary gas mixtures (CO2-CH4-N2) with unary isotherms.
# How to setup:
Running the model requires access to Matlab. the main file is: TSEMO_Main.m
Results can be read directly with any text editor. Input data can be obtained form the code.
